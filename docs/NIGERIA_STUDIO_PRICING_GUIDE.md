## 1. The Commercial Model: BUILD → RUN → MAINTAIN

Buildwith_lami enforces a strict, transparent separation between **software engineering**, **production cloud infrastructure**, and **ongoing maintenance** so clients always understand exactly what they are paying for.

```
┌────────────────────────────────┐    ┌─────────────────────────────────┐    ┌─────────────────────────────────┐
│           01. BUILD            │    │            02. RUN              │    │          03. MAINTAIN           │
│   (Design & Engineering Fee)   │ ──►│   (Production Infrastructure)   │ ──►│     (Optional Ongoing Care)     │
│  Fixed-price milestone builds  │    │  Hosting, CDN, SSL & Databases  │    │   Essential: ₦130k/yr           │
│  Starter: ₦270k | Growth: ₦520k│    │   Direct Billing (0% Markup)    │    │   Standard:  ₦60k/mo / ₦600k/yr │
│  E-Com: ₦650k   | Soft: ₦1.2M  │    │   or Managed Hosting Quote      │    │   Growth:    ₦150k/mo           │
│                                │    │                                 │    │   Pro:       ₦350k/mo           │
└────────────────────────────────┘    └─────────────────────────────────┘    └─────────────────────────────────┘
```

### Pillar Definitions:

1. **BUILD (Development & Design Fee)**:
   - One-time design & engineering fee covering the agreed project scope.
   - Billed on transparent 50/50 terms (**50% Kickoff, 50% Final Delivery**).
   - Includes **complimentary post-launch warranty support** (Web/E-Com: 14–60 days; Custom Software: 90 days) to resolve genuine defects in the delivered scope with zero maintenance fee required.
   - 100% intellectual property transfer and GitHub code repository handover.

2. **RUN (Production Cloud Infrastructure)**:
   - The hosting, database, storage, transactional email, CDN, and domain required to operate your live application.
   - **Client-Owned Infrastructure (Recommended)**: The client pays hosting and cloud providers directly (Vercel, Supabase, AWS, DigitalOcean, cPanel, Namecheap). Buildwith_lami configures and deploys where included in scope with **0% markup** on third-party infrastructure.
   - **Buildwith_lami-Managed Infrastructure**: Custom infrastructure quote per stack. Our Essential Care retainer manages and monitors your infrastructure — it does not absorb third-party hosting bills.
   - *Note*: Free hosting tiers are not equivalent to production infrastructure.

3. **MAINTAIN (Website Care & Retainers)**:
   - Optional ongoing technical care to keep your platform secure, monitored, and regularly improved after launch.
   - **Essential Care (Annual)**: `₦130,000 / year` — Annual website care & health retainer. Hosting account management, SSL certificate provisioning & renewal monitoring, automated uptime health checks with outage alerting to our team, software & dependency updates, and basic backup configuration where supported.
   - **Standard Care (Monthly or Annual)**: `₦60,000 / month` (or `₦600,000 / year` — save ₦120k) — Includes 2 hours/month developer updates, quarterly performance checkups, and standard support.
   - **Growth Care (Monthly)**: `₦150,000 / month` — Active monthly improvement retainer with up to 4 hours of dedicated developer improvement work per month, Core Web Vitals speed tuning, conversion flow testing, and prioritized support.
   - **Pro Care (Monthly)**: `₦350,000 / month` — Ongoing engineering retainer with up to 10 hours of active feature engineering per month, priority emergency support window, and quarterly architecture reviews.

## 2. Technical Performance & Responsibility Boundaries

### Concise Performance Boundary:
> *"Website performance depends on application architecture, hosting infrastructure, traffic volume, third-party services, media assets, and network conditions. Buildwith_lami targets 90+ Lighthouse scores on delivered code, while specific uptime or performance guarantees require an appropriate infrastructure tier."*

### Client Responsibility vs. Buildwith_lami Responsibility:

| Domain | Buildwith_lami Responsibility | Infrastructure / Client Boundaries |
| :--- | :--- | :--- |
| **Application Code** | Bespoke UI/UX, responsive code, database schemas, and business workflows within agreed scope. | Client-added plugins, custom scripts, or unsupported server-level edits. |
| **Performance** | Code-level optimization, asset minification, caching setup, and Lighthouse performance tuning on delivered code. | Network conditions, extreme unpredicted traffic surges exceeding the chosen hosting tier. |
| **QA & Handover** | Pre-launch staging tests, cross-browser QA, SSL cutover, and full GitHub IP transfer. | Third-party provider outages (AWS/Vercel/Cloudflare downtime) and API rate limits. |
| **Defects & Bugs** | Fixing genuine implementation bugs during the included warranty period. | Third-party SaaS payment gateways, SMS credit exhaustion, or external API failures. |

## 5. Standard Engagement Workflow

1. **Discovery & Scope Alignment**: Submit an inquiry via the [Pricing Builder](https://buildwithlami.com/pricing) or [Contact Form](https://buildwithlami.com/contact).
2. **Written Milestone Proposal**: Receive a Statement of Work with exact deliverables, boundary exclusions, timeline, and 50/50 terms.
3. **50% Kickoff Payment**: Development and design commence immediately with staging previews provided.
4. **Staging Review & 50% Balance**: Upon approval, final balance is settled, DNS is pointed to production, and the full GitHub repository is handed over.
5. **Post-Launch Warranty & Care**: Included post-launch warranty commences automatically upon cutover. Ongoing maintenance begins if subscribed.
